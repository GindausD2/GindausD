# Word-for-word voice input

The requested behavior is literal dictation: preserve fillers, repeated words, false starts, self-corrections and the original spoken languages. Wispr Flow is a reference for the speak-to-text interaction. Its automatic cleanup is not enabled here. This work does not add system-wide keyboard dictation or claim parity with Wispr Flow.

The native microphone still shows Apple partial recognition while recording. Finish now waits for a final native callback, bounded at two seconds, rather than sampling after 250 milliseconds. Audio from the same microphone tap is resampled to mono PCM16 at 16 kHz, held only in bounded memory, and sent to Max's `/v1/transcriptions` endpoint when the user finishes. The server calls OpenAI's audio **transcriptions** API using `gpt-transcribe` and a verbatim style prompt. It returns the provider's transcript directly. There is no translation endpoint or second text-model rewrite. A prompt expresses intended behavior; it cannot guarantee every word is recognized correctly.

The composer always creates an editable draft and waits for Send. Cloud failure retains the available iPhone draft with a visible review message. Direct voice sessions also stop for draft review after fallback or reaching the recording limit. Recordings are limited to two minutes; reaching the limit finishes into a reviewable draft with a notice. Cancel, account changes and background cleanup invalidate work and discard the in-memory audio. No raw audio or transcript is added to application logs. The phone permission text and capture panel disclose server transcription. Audio is sent onward to OpenAI; provider retention follows the configured provider account policy.

Deployment is required before this endpoint can work. Keep the provider key only in the backend's existing secret configuration. `OPENAI_TRANSCRIBE_MODEL` optionally overrides the default `gpt-transcribe` on the server, including in the existing beta/production entry points. Verify provider model access in the intended environment. This change does not deploy either backend, alter Apple credentials, publish a signed app, merge PR #3 or change billing/guest rules. Auth, exact seven-day demo expiry, subscription verification and the existing request quota are enforced before the provider call. Each non-silent transcription attempt reserves one existing managed-request quota unit, including provider failures; sending the resulting message uses another unit. No SQL migration is needed.

## Verification and remaining acceptance

Backend tests use synthetic PCM and provider/auth fixtures. They exercise exact text passthrough, mixed-language/filler preservation in the response contract, quota/access denial, expired demo, invalid/oversized audio, silence, cancellation, redacted diagnostics and Edge binary forwarding. Native tests cover stereo resampling/WAV headers, bounded capture/cancellation, late final recognition callbacks, verbatim draft retention, fallback notices, limit handling and no automatic composer send. They do not measure real speech recognition accuracy.

Native build/tests require Xcode. The local work environment has no Xcode or Swift compiler. Check the follow-up PR's own CI results before interpreting its simulator or unsigned device-SDK status. Signed delivery, real provider calls, physical microphone capture, accuracy and device UI remain unverified.

Run these additional checks on the signed follow-up build, alongside [DEVICE_ACCEPTANCE.md](DEVICE_ACCEPTANCE.md). Record the exact build/backend commit, iPhone/iOS, input language, recording, expected transcript, actual transcript and latency. Mark every unrun case NOT RUN or BLOCKED.

| Check | PASS | FAIL |
| --- | --- | --- |
| Word-for-word speech | For “Um, I, I mean, like, meet at two, actually three,” the draft retains every spoken word in order, including both times, repeats and fillers. Punctuation/case may vary. Nothing is sent before Send. | Missing, substituted, reordered or invented words; removing the correction/repetition; automatic composer send. |
| Names, numbers and accent | Read a prepared set containing Gindaus, Bauchi, TeemFlow, dates, times and phone numbers in the tester's natural accent. Every name/number and word matches the approved transcript. | Any mismatch. Record each error; do not claim accent support from fixture tests. |
| Language and code switching | Read prepared samples in each intended language and a mixed-language sample. Original-language words survive without an English translation or extra text. | Translation, omitted language segments or fabricated content. A language not tested remains unverified. |
| Final words and pauses | Speak a final distinct word immediately before Done; include a pause longer than two seconds during composer dictation. Draft includes the final word; a pause alone never sends/stops composer dictation. | Clipped ending, premature completion or sending on silence. |
| Silence and noise | Record silence, then representative background noise without speech. | Any invented sentence is FAIL; an empty/recoverable “couldn't catch that” outcome is PASS. Digital-silence fixtures alone do not prove this. |
| Failure and cancellation | Disable network or return a staged provider error; cancel while finishing; sign out/switch accounts while finishing. | Lost original draft, silent fallback, late text after cancellation, old-account words in a new account or automatic fallback send is FAIL. A clearly labelled reviewable iPhone fallback, or a recoverable empty result, is PASS. |
| Recording limit and resources | Dictate until the two-minute cap; check capture stops, a notice appears, draft remains editable and another capture can append. | Endless recording, hidden truncation, automatic send, stuck capture or retained local audio file. |
| End-to-end availability | Use the intended deployed backend and real provider. Final verbatim text returns into the signed app draft. Record measured processing latency. | Missing endpoint/provider configuration, unauthorized access or endless finishing. No latency promise is made until measured. |
