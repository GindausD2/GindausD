# Max UI reference update — 17 October 2026

The supplied recordings show Persona's mobile website (15:38 recording) and Starcy's iPhone Home, Profile and Memory screens (16:01 recording). Max borrows the generous spacing, restrained typography, central orb, compact page navigation and rounded controls. Brand marks, product imagery, certification claims and Starcy's multicolour orb are not copied.

The native implementation uses a glacier-blue sphere with layered glass folds and a quiet halo, a cool white canvas, a Home/Profile capsule, a compact composer and two editable draft suggestions. Conversation history and photo attachment are in the composer plus menu. Your day, speech playback and morning briefing remain reachable beneath it. Profile retains personal photos, names, Memory, Dynamic Island and Settings. Authentication now shares the cool palette; the Login/Signup slider and seven-day demo behavior are unchanged.

The orb and its caption play/stop Max. The microphone captures a voice-to-text draft for review before sending. Active states animate; the resting orb does not continuously redraw. Reduced motion, reduced transparency and older iOS glass fallbacks remain supported. Chat colours adapt to light/dark appearance. Screenshot fixtures include regular, compact, large text, accessibility fallback, dark, profile, conversation and voice draft states using isolated sample data.

Only interface code and capture fixtures changed. Physical-device microphone, haptic and Dynamic Island delivery still require device acceptance. Simulator captures do not establish those behaviors, real Apple sign-in, subscription purchases or live AI access.
